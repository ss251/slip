# Changelog

## Wave 1 pre-alpha — 2026-09-06

Landed on local `main` from the first app scaffold, `c7b3b1b`, through `6a3f706`. This is an unreleased capability record for the 2026-09-16 milestone. Historical gate quotations come from the named commit messages; linked documents retain measurements and their limits. The default app proves a single-player local round. Connected crews and an authenticated physical-iPhone → relay → devnet run are not demonstrated.

### Current local verification

Verified locally on 2026-09-06 with the prepared native archive and proving inputs, iPhone 17 Pro / iOS 27 simulator. The command was `xcodebuild -scheme Slip -destination 'platform=iOS Simulator,id=670DB62C-18B0-49C0-A910-FD8C45E4B951' -derivedDataPath /tmp/slip-luma-build test`.

`✔ Test run with 73 tests in 14 suites passed after 109.527 seconds.` / `** TEST SUCCEEDED **`

Design gate and freshness gate (`--no-network`) passed. All 120 PNG references compared without re-recording. The accessibility entries below are covered by this gate and their linked regression tests. This local result does not establish CI app-test coverage; see [build-input requirements](CONTRIBUTING.md#prepare-the-checkout).
